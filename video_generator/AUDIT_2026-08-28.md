## Rollback recuperabile

Usare `git revert`, mai `reset --hard`. Dal repository `/home/ubuntu/GIT`,
revertire in ordine inverso soltanto il commit problematico, quindi eseguire i
test e pubblicare sul remote privato:

```bash
git revert 8263181
git push private main
```

Per Conscia-Mente:

```bash
cd /home/ubuntu/conscia-mente
git revert 3e31a09
npm test && npm run lint && npm run build
git push origin main
```

Se il problema riguarda dati o file non committati, ripristinare da uno degli
archivi code-only senza sovrascrivere media o profili browser.
